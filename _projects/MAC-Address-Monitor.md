## Overview

This project was part of my university group project module in my second year! This script logs MAC addresses found through sniffing ARP requests and replys. MAC addresses are logged in a Microsoft SQL database with client side logs and error messages available.

I think the repo might be private but if you are interested shoot me a message and I can send over the code.

## How it works

MAC addresses are first captured on a network from both ARP requests and replys and DHCP packets. These are logged into a SQL database which can then compare them against a set predefined list that a user can set. The program also has wiper scripts plus a way to upload a whitelist.
